# Pathland Conformance Test Vectors

**Wire protocol version:** 1
**Encoding:** little-endian

This document provides **golden byte arrays** for the Pathland binary protocol (see [BINARY_PROTOCOL.md](./BINARY_PROTOCOL.md)). Each vector is a complete message: header + instructions. A conforming implementation MUST:

- encode the given command(s) to exactly these bytes, and
- decode these bytes to the equivalent command(s).

The vectors were generated by the reference TypeScript encoder (`@pathland/protocol`).

## Conventions

- **Header**: `[version u16 = 0x0001][instructionCount u32]`
- **Instruction**: `[opcode u8][payloadLength u16][payload...]`

## Vectors

### 1. CREATE_NODE (VSTACK, no properties)

Command:
```
CREATE_NODE { nodeId: 1, componentType: VSTACK (0x0002), properties: [] }
```

Message:
```
01 00 01 00 00 00 01 07 00 01 00 00 00 02 00 00
```

Breakdown:
- `01 00` version = 1
- `01 00 00 00` instructionCount = 1
- `01` opcode = CREATE_NODE
- `07 00` payloadLength = 7
- `01 00 00 00` nodeId = 1
- `02 00` componentType = VSTACK
- `00` propertyCount = 0

### 2. CREATE_NODE (TEXT, inline text property)

Command:
```
CREATE_NODE { nodeId: 2, componentType: TEXT (0x0003),
              properties: { TEXT (0x000A): "Hello" } }
```

Message:
```
01 00 01 00 00 00 01 13 00 02 00 00 00 03 00 01 0a 00 05 05 00 00 00 48 65 6c 6c 6f
```

Breakdown (instruction payload, length 19 = `13 00`):
- `02 00 00 00` nodeId = 2
- `03 00` componentType = TEXT
- `01` propertyCount = 1
- `0a 00` propertyId = TEXT (0x000A)
- `05` valueType = STRING
- `05 00 00 00` string byteLength = 5
- `48 65 6c 6c 6f` "Hello"

### 7. SET_DESIGN_TOKEN (color.primary -> ACCENT)

Command: `SET_DESIGN_TOKEN { tokenPath: "color.primary", value: { color, semantic, tokenId: ACCENT (0x0006) } }`

```
01 00 01 00 00 00 06 15 00 0d 00 00 00 63 6f 6c 6f 72 2e 70 72 69 6d 61 72 79 07 01 06 00
```

## Not covered by fixed vectors

Event encodings that carry a **timestamp** (e.g., `DISPATCH_EVENT`, `GESTURE_UPDATE`) are intentionally not given fixed vectors: the timestamp bytes are non-deterministic. Their field layout is defined in [BINARY_PROTOCOL.md - Event System](./BINARY_PROTOCOL.md#event-system) and [Gesture System](./BINARY_PROTOCOL.md#gesture-system).

## Generating vectors

The vectors are produced by the reference encoder:

```typescript
import { encodeMessage } from '@pathland/protocol';
const bytes = encodeMessage(commands); // Uint8Array
```
