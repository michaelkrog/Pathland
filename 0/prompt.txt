# TASK: Replace Rust Codegen with Native Java 21+ Pathland DSL & Build Quarkus SSR + WebSocket Demo with Cross-Platform State

## OVERVIEW & OBJECTIVES
We currently have a Java DSL for our UI framework that is auto-generated from Rust via a codegen crate. This codegen approach is fragile, error-prone, and difficult to maintain. 

We want to **completely delete/remove the Rust codegen crate** from the codebase and replace it with a hand-crafted, zero-dependency native Java 21+ DSL inspired by SwiftUI ergonomics (`View` records, modifiers, environment scoping, reactive state).

Additionally, we want to create a **new Quarkus demonstration application** (`pathland-quarkus-demo`) showcasing:
1. Server-Side Rendering (SSR) emitting static HTML (`pathland-render-html`) for instant First Contentful Paint.
2. WebSocket streaming of fine-grained, 16-byte binary Pathland opcodes (`deltas`) for real-time interactive UI updates.
3. A cross-platform state persistence architecture that works seamlessly across multi-tenant scale-out servers (Redis), Desktop apps (File/SQLite), Browser WASM (LocalStorage), and Embedded ESP32 microcontrollers (NVS Flash).

---

## 1. CODEBASE CLEANUP & REFACTORING
* **Purge Codegen:** Delete all source files and build configurations associated with the Rust Java codegen crate.
* **Architecture Shift:** Replace all references to generated Java bindings with the new hand-crafted Java 21+ DSL specified below.
* **Rust Core Integration:** Retain the core Rust SPSC Ring Buffer and 16-byte opcode engine compiled as a static/shared C-ABI library (`libpathland_core.so` / `.dylib` / `.dll`).

## 2. NATIVE JAVA 21+ DSL ARCHITECTURE (`com.pathland.dsl`)

### A. Zero-Copy C-ABI Interop via Java FFM (Java 22+)
* Define the 16-byte packed C-struct layout for Pathland Opcodes matching the Rust core specification:
  - `u8` Opcode Type (1 Byte)
  - `u32` Target Node ID (4 Bytes)
  - `u16` Property ID (2 Bytes)
  - `u64` Payload / Pointer / Value (8 Bytes)
* Connect Java to the compiled Rust library using Java's Foreign Function & Memory (FFM) API (`java.lang.foreign`).
* Bind to the Rust native entry point: `bool pathland_ring_buffer_push(const PathlandOpcode* ptr)`.
* Use `Arena.ofAuto()` and `MemorySegment` to pass opcode buffers to C-ABI with **zero JNI overhead and zero heap allocations**.

### B. Core View Model & SwiftUI Ergonomics
* **`public sealed interface View`**: The fundamental view contract. Must contain `PathlandNode render(Environment env)` and default modifier helpers.
* **Leaf Primitives:** Implement `Text`, `Image`, `Color`, `Rectangle`.
* **Layout Primitives:** Implement `VStack`, `HStack`, `ZStack` accepting child view composition via `List<View>` or variadic constructors.
* **Interactive Controls:** Implement `Button(View label, Runnable action)` accepting arbitrary child views as custom labels, with convenience constructors for string titles (`Button(String title, Runnable action)`).
* **Input Primitives:** Implement `TextField(String placeholder, Binding<String> binding)`.

### C. Environment Scoping (`ScopedValue<T>`)
* Use Java 21+ **`ScopedValue<T>`** (Project Loom) for scoped parent-to-child environment propagation (e.g., active color schemes, button styles).
* Define a `ButtonStyle` interface with `View makeBody(Configuration config)`.
* Add a default `.buttonStyle(ButtonStyle style)` method on `View` to allow parent layout containers (`VStack`) to inject button styling down the entire child tree.
* Implement default built-in styles: `BorderedButtonStyle` and `PlainButtonStyle`.

### D. Reusable View Modifiers (`ViewModifier`)
* Define a functional interface `@FunctionalInterface public interface ViewModifier { View body(View content); }`.
* Add a default `.modifier(ViewModifier modifier)` method on `View` to enable external developers to create custom style wrappers (e.g., `.modifier(new CardStyle())`).
* Include standard convenience modifier methods like `.padding(int pixels)` and `.background(Color color)`.

### E. Reactive State & Bindings
* Implement a strongly typed, zero-copy `Binding<T>` record:
  `public record Binding<T>(Supplier<T> getter, Consumer<T> setter)`
